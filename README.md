# Lung Cancer Analysis using Exploratory Data Analysis (EDA)

## Overview
This project involves an exploratory data analysis (EDA) of lung cancer data. The goal is to identify patterns, correlations, and key insights that can help understand factors associated with lung cancer. The analysis was performed on a dataset containing demographic, lifestyle, and health-related attributes of individuals.

## Key Insights
1. **Prevalence of Lung Cancer:**
   - 50.6% of the dataset's individuals have lung cancer.
   - 49.4% of individuals do not have lung cancer.

2. **Impact of Smoking:**
   - Smokers are slightly more prevalent in the dataset.

3. **Gender Distribution:**
   - Lung cancer affects males and females almost equally, with only a small difference in prevalence.

4. **Age Factor:**
   - Individuals between the ages of 40 and 80 are the most affected by lung cancer.

5. **Chest Pain Correlation:**
   - Lung cancer patients experience more chest pain compared to those without the disease.

6. **Symptoms Associated with Lung Cancer:**
   - Yellow fingers
   - Wheezing
   - Coughing
   - Fatigue
   - Shortness of breath
   - Chest pain

These symptoms are indicative of lung cancer and can be used as markers for early diagnosis.

## Technologies Used
- **Python**: For data analysis and visualization
- **Libraries**: Pandas, Matplotlib, Seaborn, NumPy

## Dataset
The dataset contains attributes related to:
- Demographics: Age, gender
- Lifestyle: Smoking habits
- Symptoms: Various health indicators

## Analysis Process
1. **Data Cleaning:** Handled missing values and corrected data inconsistencies.
2. **Exploratory Data Analysis (EDA):** Utilized visualizations and statistical methods to uncover patterns.
3. **Feature Correlation:** Identified key symptoms and factors associated with lung cancer.

## Results
The analysis highlights significant factors like smoking, age, and specific symptoms that correlate with lung cancer. These insights can help inform healthcare initiatives and early detection efforts.

## Conclusion
This project sheds light on the critical factors associated with lung cancer, enabling better understanding and supporting future research in this domain.
